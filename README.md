# Clase4_Aprendizaje_Automatico
En esta clase trabajamos con tres ejercicios distintos de aprendizaje automático, cada uno basado en un dataset diferente.
Datasets utilizados

1) PIB de 50 países

Objetivo: encontrar una posible relación o linealidad entre el PIB (Producto Interno Bruto) de diferentes países del mundo.

2) Clasificación de usuarios según sistema operativo

Objetivo: predecir el sistema operativo de un usuario a partir de sus interacciones (duración, páginas visitadas, acciones, valor).

3) Predicción de presión arterial

Objetivo: predecir la presión arterial de personas usando variables explicativas (horas de sueño, actividad física, etc.).

Tecnologías utilizadas

-Python 3

-Pandas, NumPy

-Scikit-learn

-Matplotlib, Seaborn

-Jupyter Notebook

Los datasets están incluídos en la carpeta "Datasets" y las 3 Jupyter Notebooks están en la carpeta "Notebooks".
